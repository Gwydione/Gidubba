# Gidubba 1.6.0

Gidubba 1.6.0 adds **Complete Result**: when one roll leads on to linked tables, the whole outcome is put together in one
readable place on the Roll screen, while every individual roll stays visible below it. Nothing else about rolling
changes, and **your data is not changed:** Gidubba 1.5.1 can still open it afterwards.

## Highlights

- **New: Complete Result.** When you follow a link (with **Open** or with **Auto-follow linked tables**), or one **Roll**
  makes several results, a **Complete Result** panel at the top of the Roll screen shows the results together, in the
  order they were resolved. It uses each result's own text exactly as written; Gidubba never writes new text.
- **Every roll is still there.** The table names, dice, modifiers, clamped values, links and inline dice of each roll stay
  in the trail below, exactly as before. A small caption above each part of the panel says which table and roll it came
  from ("Occupants · 11 (resolved as 10)").
- **It keeps up as the chain resolves.** Each linked roll is added as soon as it resolves (with dddice, once the dice
  settle). A linked table you have opened but not rolled yet is shown as "→ Loot — not rolled yet", and a
  Manual-selection table as "choose a result". Rolling a linked table again replaces that table's part in the same place.
- **Copy Complete Result** copies the result text only, one result per line, ready to paste into a journal, a chat or
  your notes. A "No entry covers N." message is copied with its table's name.
- **Rolled inline dice keep their value.** When you roll `1d4` in "gain 1d4 Armor" and then follow a link or roll again,
  that result keeps its **Resolved:** line ("gain 3 Armor"), and the Complete Result uses it. Only the current result can
  be rolled, as before; an expression nobody rolled stays as written.
- **← Back to …** keeps the previous Complete Result until your next roll starts a new one.
- **New (optional): Complete Result on the Streaming Overlay.** In **Streaming Overlay…**, **Overlay shows: Complete result**
  shows your OBS viewers the whole chain as it grows ("WALL SHRINE", its description, then the god it is dedicated to),
  instead of only the latest table's result. Each later result is headed with its table and roll, as **Show table name**
  and **Show roll value** say. **Latest roll** stays the default, ordinary single rolls look the same either way, and your
  existing OBS Browser Source needs no change or refresh.
- **Ordinary rolls look exactly as before.** A single roll with no links shows no panel.
- **Unchanged:** dice (Built-in and dddice), Auto-follow, Unique Results, Recent rolls, the Streaming Overlay (unless you
  choose Complete result), exports, the installer and your data folder. **The data format does not change** (still database schema version 12).

## Installation

1. Download `Gidubba-1.6.0-Setup.exe` below.
2. Run it. It installs for your Windows user only, with no administrator prompt, into `%LOCALAPPDATA%\Programs\TableForge`.
   If Gidubba 1.5.1 (or an earlier Gidubba or TableForge) is installed, leave it installed: 1.6.0 replaces it in place.
3. Start **Gidubba** from the Start Menu.

Requires 64-bit Windows 10 or 11. .NET is included. The Microsoft Edge WebView2 Runtime (part of Windows 11 and current
Windows 10) is needed only for dddice dice; Built-in dice always work.

Gidubba is **not code-signed**, so Windows SmartScreen may warn about it. If you trust this download, choose
**More info** → **Run anyway**. Check the file against `SHA256SUMS.txt` by running
`Get-FileHash .\Gidubba-1.6.0-Setup.exe` in PowerShell.

Also attached: `Gidubba-1.6.0-win-x64.zip`, the same program without an installer. Extract it and run
`TableForge.exe`. It uses the same data folder.

## Known Issues

- The Complete Result is not saved and not listed in Recent rolls. The Streaming Overlay shows it only with **Overlay
  shows: Complete result**; otherwise it shows the latest roll's result, as before. Opening another table starts afresh.
- The overlay does not resize to fit a long chain: text below the Browser Source's height is cut off by OBS. Make the source
  taller, or use smaller text with its **Custom CSS** (for example `.tf-result { font-size: 24px; }`). A chain over 20
  lines or 4000 characters shows its first result, "…" and the newest results.
- Inline dice in results that Auto-follow rolled past cannot be rolled any more (only the current result can be), so
  they stay as written in the Complete Result.
- In a small window with Recent rolls open, the panel is only a line or two high and scrolls; click its heading to close
  it and give the rolls below more room.
- The panel's text is not a Tab stop of its own. With its heading or **Copy Complete Result** focused, **Page Up**,
  **Page Down**, **Home** and **End** scroll it.
- Everything listed under Known Issues in the 1.5.0 and 1.5.1 release notes still applies.

## Data and Upgrades

Your tables and settings live in `%LOCALAPPDATA%\TableForge` (**Open Data Folder** shows it). Installing 1.6.0 over
1.5.1 keeps them, uninstalling Gidubba does **not** delete them, and reinstalling finds them again.

- **The data format does not change** (still database schema version 12). No safety copy is made, because nothing is
  updated. Collection files are unchanged, and no new files are added to the data folder. The overlay's settings file
  gains one setting, **Overlay shows**; 1.5.1 ignores it and shows the latest roll.
- **Gidubba 1.5.1 can still open data that 1.6.0 has used.** To go back, reinstall 1.5.1.
